# muhammadbahauddin.github.io

Personal portfolio of **Muhammad Bahauddin**, Senior Web Developer.

Live: https://muhammadbahauddin.github.io

Plain HTML, CSS and JavaScript: no build step. Edit `index.html`, `css/style.css` or `js/main.js` and push to `main`.

- Project case studies are defined in the `PROJECTS` array at the top of `js/main.js`.
- Screenshots live in `assets/projects/<slug>/` (`cover`, `home`, `inner`, `mobile` as `.webp`).
- CVs live in `cv/`.
